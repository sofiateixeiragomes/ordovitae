Bloco 5

Triagem laboratorial

Os exames precisam estar válidos na data do retiro — ou seja, realizados a partir de abril de 2026.

Responda todos, mesmo que seja para marcar "Não realizei" — nesse caso a coordenação envia o pedido para você. Se já fez, basta digitar o resultado; anexar o laudo é opcional.

Preenche a data de todos os exames de uma vez. Se algum foi feito em outro dia, é só corrigir naquele exame.

Já tem o laudo com vários exames?

Anexe aqui de uma vez, em vez de repetir o arquivo exame por exame. Pode selecionar mais de um — se o laudo tem várias páginas, envie todas.

Mesmo anexando o laudo, marque abaixo o que foi realizado — é assim que a coordenação sabe o que ainda falta pedir para você.

Depois é só desmarcar o que não estiver no laudo.
